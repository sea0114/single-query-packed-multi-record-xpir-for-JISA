\paragraph{Composition of task failure probabilities.}
For two independent fresh-key single-record executions with actual ideal
failure probabilities \(d_1,d_2\), the two-record task has failure
\[
 d_{\rm rep}=1-(1-d_1)(1-d_2)\le d_1+d_2.
\]
If only bounds \(d_i\le\varepsilon_i\le1\) are known, then
\(d_{\rm rep}\le1-(1-\varepsilon_1)(1-\varepsilon_2)
\le\varepsilon_1+\varepsilon_2\); equality with the bounds is not asserted.
For identical actual rates this is \(1-(1-d_1)^2\).
The two executions share one complete-task reliability budget.
